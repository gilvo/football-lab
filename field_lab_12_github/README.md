# FIELD LAB 12.0

정적 GitHub Pages 웹앱. 16명 / 40개 SVG 전술 / 기존 31개 MP4 / 상황 훈련 15개 / 퀴즈 15개 / 전술 편집 / 7개 포메이션.

## 배포
1. ZIP 압축을 푼 다음 내부의 `index.html`, `media/`, `manifest.webmanifest`, `sw.js`, 아이콘, `.nojekyll`을 저장소 최상위에 업로드합니다.
2. GitHub 저장소 Settings → Pages → Deploy from a branch → main / (root) → Save.
3. 배포된 HTTPS 주소를 iPhone Safari에서 엽니다. 이전 버전이 보이면 새로고침 후 재접속하세요.

## 사용
- 전술 시뮬레이터: 포지션/선수/전술 선택. 기존 장면은 MP4도 지원, 신규 9개는 SVG 전용.
- 상황 판단/퀴즈: 선택 후 해설 및 관련 전술 확인. 기록은 브라우저에 로컬 저장.
- 전술 편집: 포메이션 선택 후 선수 이동, 시작/결과 위치 편집, 화살표와 공 배치, 재생, 저장 및 JSON 공유.
- 학습용 재구성 전술로 실제 경기 트래킹 데이터가 아닙니다. 영상 링크는 인터넷 연결이 필요합니다.
- 공개 저장소 및 웹사이트에는 개인 정보나 비공개 팀 전략을 올리지 마세요. 편집 기록은 로컬이며 다른 이용자와 자동 공유되지 않습니다.
- 서비스 워커는 앱 기본 파일을 캐시하며 MP4 및 외부 영상의 오프라인 재생을 보장하지 않습니다.
